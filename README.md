# Project 1 - Cryptography

Permutation cipher (student ID 161462, 161462 mod 3 = 2).

Permutation: `[2, 0, 4, 1, 5, 3]` (block of 6 letters).

## How to run

```
python szyfr.py
```

## Example

```
Plaintext:  Ala ma kota
Ciphertext: AAALKMAOXTXX
```

Handled errors: empty text, characters other than letters A-Z, wrong ciphertext length, wrong menu option.
